# Архив неподключённого кода

Здесь сохранены прежние маршруты и сервисы, которые не были зарегистрированы в приложении 0.6.5. В runtime они не импортируются. В старых путях оставлены только поясняющие модули без маршрутов.

Действующий административный `/users/import-legacy` из `app/api/routes/users_import.py` сохранён; его уникальность аккаунтов и отзыв токенов исправлены. Сервис `accounting_receipt_data_fix.py` остаётся действующим и не архивировался. Все исторические миграции Alembic сохранены.

Корневой `eng.traineddata` оставлен для совместимости с возможной настройкой TESSDATA_PREFIX на действующем сервере. Его удаление требует проверки этой настройки.
