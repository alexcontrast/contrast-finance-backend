# Contrast Finance v0.5.65

Аварийный патч запуска после `v0.5.64`.

## Изменено

- В комплект возвращён актуальный `monthly_closings.py` с функциями `calculate_closing` и `apply_calculated_to_closing`, которые использует выплата бонуса менеджеру.
- `manager_bonuses.py` и `monthly_closings.py` поставляются одной совместимой парой.
- Google Sheets, автосохранение, сброс PIN и расчёты бонусов не изменялись.

## Деплой

Для быстрого восстановления можно развернуть `v0.5.65_CHANGED_ONLY.zip` поверх текущего `v0.5.64`.

Также собран `v0.5.65_FULL.zip` — полное актуальное дерево проекта, чтобы деплой больше не зависел от состава старых патчей.

Новых миграций нет. Миграция `0013_manager_bonus` уже применена и остаётся текущей.
