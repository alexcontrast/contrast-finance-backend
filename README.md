# Contrast Finance v0.5.69

Ускорение первой загрузки месяца и мгновенное повторное открытие уже посещённых месяцев.

## Изменено

- Компактный endpoint выбирает только поля, реально нужные первому экрану и финансовому калькулятору.
- Повторный SQL-запрос оплаченных сумм удалён: запросов стало 10 вместо 11.
- Последний готовый месяц показывается из локального кэша сразу и обновляется с сервера в фоне.
- После любого финансового изменения кэш очищается, поэтому старые цифры не подменяют свежий расчёт.
- Соседние месяцы готовятся после текущего; подробная карточка загружается только для открытого мероприятия.
- JS и CSS сжимаются GZip и кэшируются по версии: первая передача уменьшается примерно с 1,1 МБ до 168 КиБ, повторная сеть не требуется.
- Быстрый и полный расчёты проверены на полном совпадении итогов.

## Деплой

Развернуть `v0.5.69_CHANGED_ONLY.zip` поверх текущего `v0.5.68`.

Схема базы данных и финансовые формулы не менялись, новых миграций нет.
