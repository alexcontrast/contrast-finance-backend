# Contrast Finance v0.5.63

Патч выплаты месячного бонуса менеджеру после выполнения личного плана.

## Изменено

- Кнопка 💰 в админском «Обзоре» активируется после выполнения плана выбранного месяца.
- Бонус равен 5% от факта дохода менеджера, используемого в прогрессе личного плана.
- Выплата создаёт защищённый расход выбранного месяца в отделе менеджера.
- Повторная выплата за тот же месяц заблокирована на уровне базы данных.
- Бонус добавляется к «ЗП» менеджера в общей годовой статистике.
- Закрытый месяц пересчитывается, если бонус за него выплатили позднее.

## Деплой

Обычный деплой поверх `v0.5.62`. При запуске автоматически применяется миграция `0013_manager_bonus`.
