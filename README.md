# Contrast Finance v0.5.60

Точечный патч восстановления доступа менеджера администратором.

## Добавлено

- Во вкладке «Обзор» рядом с кнопкой удаления менеджера появилась кнопка с замком для задания нового PIN.
- Окно предлагает готовый случайный PIN, позволяет заменить его своим и скопировать после сохранения.
- Старый PIN не показывается и не хранится в открытом виде.
- Сброс корректно работает и для менеджеров, перенесённых из старой системы.

## Деплой

Обычный деплой. Миграций базы данных нет.
