# Contrast Finance v0.5.66

Точечное обновление компоновки строк менеджеров в админском обзоре.

## Изменено

- Кнопки больше не сокращают имя менеджера за счёт неявной колонки.
- Факт и цель дохода показаны двумя строками.
- Процент выполнения расположен под шкалой.
- Выплаченный бонус подсвечивается мягко-зелёным.
- Кнопка смены PIN стала серой.

## Деплой

Развернуть `v0.5.66_CHANGED_ONLY.zip` поверх текущего `v0.5.65`.

Backend и база данных не менялись. Новых миграций нет.
