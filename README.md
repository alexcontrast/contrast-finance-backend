# Contrast Finance v0.5.74

Точечный патч поверх `v0.5.73`: убирает частый ложный конфликт строки сметы после изменений статусов заявок/оплат, не отключая защиту от настоящего одновременного редактирования.

## Исправлено

- Пересчёт производного поля `paid_amount` больше не меняет `EventItem.updated_at`.
- Оплата/отмена заявки в админке или Telegram больше не делает открытую строку сметы «устаревшей».
- При 409 веб один раз безопасно подтягивает свежую строку и автоматически объединяет непересекающиеся изменения.
- Аналогично обрабатывается служебное изменение ревизии самого мероприятия.
- Настоящий конфликт одного и того же поля в двух вкладках по-прежнему блокируется.
- Live-sync не перезаписывает baseline открытого грязного черновика.

## Деплой

Развернуть `v0.5-2.74_CHANGED_ONLY.zip` поверх текущего `v0.5-2.73` либо использовать полный архив `v0.5-2.74_FULL.zip`.

Схема базы данных не менялась, новых миграций нет.
