# Contrast Finance v0.5.106

Актуальный кумулятивный патч поверх **v0.5.103**.

## Что исправляет

### Даты чеков e-Salyq

Дата выписки чека является источником истины для:

- месяца во вкладке «Бухгалтерия»;
- даты выполнения работ;
- даты будущего/пересозданного АВР Р-1.

Поддерживаются:

- `28.08.2026` и `28.08.2026 13:36`;
- `28 августа 2026 г.` и варианты со временем;
- казахские названия месяцев (`28 тамыз 2026 ж.`, `2026 жылғы 28 тамыз`);
- ISO date/datetime;
- Unix timestamp;
- Java/Jackson-массивы вроде `[2026, 8, 28, 13, 36, 0]`;
- объекты дат `{year, monthValue, dayOfMonth, hour, minute}`.

Технические `response/create/upload/generated` timestamps больше не должны становиться датой чека. Если реальная дата не найдена, хранится пустое значение, а не сегодняшняя дата.

После деплоя кнопка **«Обновить»** в бухгалтерии повторно читает уже сохранённые чеки через QR/КГД. Когда `receipt_datetime` исправляется, строка автоматически перемещается в месяц выписки чека.

### Казахские ФИО

ФИО и услуги обрабатываются как Unicode. Сохраняются казахские символы:

`Ә Ғ Қ Ң Ө Ұ Ү Һ І`

Например, `СЕРІКБАЙ БЕКЗАТ НҰРЕИСАҰЛЫ` должен сохраняться без вырезания букв.

QR/КГД остаётся главным источником данных. OCR используется только как резерв.

## Важно: установка

Этот ZIP специально содержит **одну корневую папку `v0.5-2.106/`**.

После распаковки открой её и загружай в корень GitHub **содержимое этой папки**. В ней находятся:

- `app/`
- `README.md`
- `CHANGELOG.md`

Не загружай папку `app` как отдельную новую папку рядом со старой. В GitHub файлы из `app/...` должны **заменить** соответствующие существующие файлы `app/...`, а не создать `app-2` / `app-3`.

## После деплоя

1. Дождаться успешного Railway deploy.
2. Сделать `Cmd+Shift+R` на macOS / `Ctrl+F5` на Windows.
3. Открыть месяц, где сейчас лежат чеки с прочерком или неправильной датой.
4. Нажать **«Обновить»**.
5. Успешно перечитанные чеки должны получить дату и переместиться в свои месяцы.
