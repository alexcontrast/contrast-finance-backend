# Contrast Finance v0.5.62

Патч защиты новых строк сметы от двойного создания.

## Изменено

- Автосохранение и ручное сохранение одной строки больше не создают два параллельных запроса.
- Повторная доставка запроса на создание строки безопасно возвращает уже созданную позицию.
- Две позиции объединяются только тогда, когда это один и тот же запрос одной временной строки; намеренно добавленные одинаковые строки остаются отдельными.
- Версионное автосохранение, локальная резервная копия, фильтр пустых строк и правило «Enter не добавляет позицию» сохранены.

## Деплой

Обычный деплой поверх `v0.5.61`. Миграций базы данных нет.
