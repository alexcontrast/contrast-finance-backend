# Contrast Finance v0.5.61

Патч стабильности заполнения и сохранения сметы менеджера.

## Изменено

- `Enter` больше не создаёт новую строку сметы.
- Строка создаётся только кнопкой «Добавить позицию» или из сценария новой позиции в заявке на оплату.
- Автосохранение стало версионным и больше не затирает свежий ввод поздним ответом сервера.
- Пустые временные строки не сохраняются.
- Старый PIN не показывается и не хранится в открытом виде.
- Сброс корректно работает и для менеджеров, перенесённых из старой системы.

## Деплой

Обычный деплой. Миграций базы данных нет.
