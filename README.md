# Contrast Finance v0.5.73

Точечный патч поверх `v0.5.72`: создание заявок на оплату больше не зависит от того, доступно ли обычное редактирование сметы.

## Исправлено

- Менеджер может отправить заявку на статусах Черновик, На проверке, На доработке, Принято и других статусах мероприятия.
- Единственная блокировка новой заявки: мероприятие одновременно **Принято** и **Деньги в кассе**.
- Смета на проверке/после принятия не разблокируется для обычного редактирования. Платёж меняет только разрешённые служебные поля выбранной позиции.
- Нал, На карту, По счету/КГД и Самозанятый проходят через этот отдельный платёжный контур.
- Новую фактическую позицию из окна «Оплатить» можно создать и после отправки сметы на проверку через ограниченный payment-only endpoint.
- Backend дополнительно проверяет закреплённый способ оплаты, чтобы ограничение нельзя было обойти прямым API-вызовом.

## Деплой

Развернуть `v0.5-2.73_CHANGED_ONLY.zip` поверх текущего `v0.5-2.72` либо использовать полный архив `v0.5-2.73_FULL.zip`.

Схема базы данных не менялась, новых миграций нет.
