# Contrast Finance v0.5.68

Комплексная оптимизация загрузки админки и переключения её вкладок.

## Изменено

- Первый экран больше не ждёт полные сметы и подробные карточки всех мероприятий месяца; они догружаются после показа админки.
- Пользователи, расходы и готовый расчёт закрытия месяца входят в компактный стартовый пакет и не запрашиваются повторно.
- «Обзор», мероприятия, архивы и заявки переключаются локально; искусственная задержка вкладок удалена.
- Планы выбранного года заранее подгружаются в фоне, а годовая статистика сохраняет пакетную оптимизацию v0.5.67.
- На контрольном месяце из 40 мероприятий, 480 позиций и 200 заявок стартовый JSON уменьшен примерно на 82%.
- Полные карточки, компактный dashboard и расчёт закрытия проверены на полное совпадение данных.

## Деплой

Развернуть `v0.5.68_CHANGED_ONLY.zip` поверх текущего `v0.5.67`.

Схема базы данных и финансовые формулы не менялись, новых миграций нет.
