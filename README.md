# Contrast Finance v0.5.64

- Восстановлена функция `build_year_statistics_sections`, которую импортирует маршрут Google Sheets.
- Маршрут и сервис годовой статистики синхронизированы и поставляются вместе.
- Бонусы менеджеров из `v0.5.63` продолжают входить в строку «ЗП» годовой статистики.
- Другие расчёты и интерфейсы не изменялись.
