# Contrast Finance v0.5.75

Первый рабочий MVP вкладки «Бухгалтерия» для заявок `Самозанятый`.

## Что появилось

- Новая вкладка «Бухгалтерия» в админке; пользователь с ролью `accountant` получает отдельный упрощённый кабинет только с этой вкладкой.
- Все заявки `Самозанятый` выбранного месяца попадают туда автоматически, включая старые.
- Загрузка и хранение оригинала чека e-Salyq Business (JPG/PNG/WEBP/PDF, до 10 МБ).
- Для изображений — тестовое локальное распознавание QR/OCR в браузере с извлечением ФИО, ИИН, номера/даты, услуги и суммы.
- Ручная проверка и корректировка распознанных данных.
- Сверка суммы чека с суммой заявки.
- Защита от загрузки одного и того же файла чека в разные заявки.
- Подготовлено поле статуса будущего АВР, но Р-1 и SIGEX пока не включены: сначала проверяется качество распознавания на реальных чеках.

## Важно перед деплоем

В этой версии **есть миграция базы данных**: `0014_self_employed_accounting`. Стандартный startup с `alembic upgrade head` должен применить её автоматически.

Для тестового этапа оригиналы чеков хранятся в PostgreSQL, чтобы не зависеть от временной файловой системы Railway. Перед массовой загрузкой сотен/тысяч документов имеет смысл отдельно выбрать постоянное object storage.

Автораспознавание изображений выполняется в браузере. Модули OCR/QR загружаются только при первом использовании; если они недоступны, чек всё равно сохраняется и поля можно заполнить вручную.
