# Contrast Finance v0.5.72

Точечный патч Telegram-бота поверх `v0.5.71`: гарантированная отмена создания заявки на любом шаге и более заметная сумма в карточке заявки.

## Исправлено

- Кнопка нижнего меню «Отменить» вызывает тот же обработчик, что и `/cancel`, во всех состояниях создания заявки.
- Текстовые этапы больше не могут принять слово «Отменить» за название позиции, БИН/ИИН, сумму, номер карты или комментарий.
- После отмены очищается весь временный payload заявки; новая заявка всегда стартует без данных предыдущего незавершённого сценария.
- В карточках заявки сумма вынесена в отдельную строку `🟢 СУММА ЗАЯВКИ`, сделана жирной и подчёркнутой. Изменение действует для менеджера, администратора и Татьяны через единый formatter.

## Деплой

Развернуть `v0.5-2.72_CHANGED_ONLY.zip` поверх текущего `v0.5-2.71` либо использовать полный архив `v0.5-2.72_FULL.zip`.

Схема базы данных и финансовые формулы не менялись, новых миграций нет.
