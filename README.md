# Contrast Finance v0.5.58

Точечный расчётный патч для строки «Налоги к уплате».

## Исправлено

- «Упрощёнка»: налог к уплате равен 5% от полного оборота и не уменьшается на вычеты подрядчиков.
- ОУР: налог к уплате по-прежнему уменьшается на доступные налоговые вычеты.
- Backend, сохранённая сводка, экран менеджера, админское редактирование и Google Sheets export используют одно исправленное значение.
- Локальный предпросмотр несохранённой сметы применяет то же правило.

## Деплой

Обычный деплой. Миграций базы данных нет. Уже существующие мероприятия пересчитаются автоматически при следующей загрузке.
