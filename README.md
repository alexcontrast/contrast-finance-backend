# Contrast Finance v0.5.70

Глубокая ревизия кабинета менеджера: быстрая загрузка, согласованность между браузерами и защита смет от повторных и устаревших сохранений.

## Изменено

- Стартовый пакет месяца сокращён с 925,6 до 26,8 КиБ; полная смета загружается одним запросом только при открытии мероприятия.
- Последний готовый месяц появляется сразу из локального кэша и обновляется в фоне.
- Версии мероприятия и каждой строки сметы защищают свежие данные от перезаписи старым браузером.
- Live-sync видит изменения позиций, КГД, координатора и заявок и обновляет только затронутые карточки.
- Автосохранение и ручное сохранение сериализованы; повторные клики и фоновые обновления не создают дубли.
- Создание строки идемпотентно, включая сценарий КГД; при ошибке проверки незавершённая позиция откатывается.
- Устаревший локальный черновик не восстанавливается без предупреждения.
- Менеджер не может изменить принятую смету обходным API-запросом.
- Компактный и полный расчёты проверены на полном совпадении финансовых итогов.

## Деплой

Развернуть `v0.5.70_CHANGED_ONLY.zip` поверх текущего `v0.5.69`.

Схема базы данных и финансовые формулы не менялись, новых миграций нет.
