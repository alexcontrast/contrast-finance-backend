# Contrast Finance v0.5.107

Исправление распознавания чеков e-Salyq поверх текущей ветки v0.5.106 / backend v0.5.103.

## Что исправлено

### Исправления действительно подключены к backend

В предыдущем пакете README обновился, но рабочий `app/main.py` в репозитории не подключал parser-fix, а `app/core/config.py` оставался на версии 0.5.103. В v0.5.107 `main.py` явно вызывает `apply_accounting_receipt_data_fix()` при запуске, а `/api/status` должен возвращать `0.5.107`.

### Дата чека

QR/KGD остаётся главным источником. Parser понимает строковые, ISO, Unix и Java/Jackson представления даты, русские и казахские названия месяцев. Технические даты ответа/загрузки не подменяют дату выписки чека.

После `Обновить` исправленный `receipt_datetime` определяет:
- месяц строки в «Бухгалтерии»;
- дату выполнения работ;
- дату формируемого АВР Р-1.

### Казахские ФИО

ФИО обрабатывается как Unicode (`str.isalpha()`), без ограничения русским диапазоном. Поддерживаются казахские буквы `Ә Ғ Қ Ң Ө Ұ Ү Һ І`.

Резервный browser OCR теперь действительно создаёт worker с `kaz+rus+eng`; в прежнем патче перехватывался только `recognize()`, тогда как приложение использует `Tesseract.createWorker()`.

### ИИН

Приоритет у официального KGD-поля исполнителя. Дополнительный parser ищет `ИИН / IIN / ЖСН`, а в резервном OCR безопасно исправляет типичные путаницы внутри ИИН: `О/O → 0`, `І/I/l → 1`. БИН заказчика Contrast Event исключается.

### Номер чека

Номер выбирается только из контекста `check/receipt number` или печатной строки `Чек №...`; `check_id`, `ip_reg_id` и другие идентификаторы не могут стать номером чека. Печатное значение официального отчёта КГД имеет наивысший приоритет.

## Установка

Архив содержит одну корневую папку `v0.5-2.107/`. Откройте её и загрузите её содержимое в корень GitHub с заменой существующих файлов.

После деплоя обязательно проверьте:
1. `https://<ваш-домен>/api/status` → версия `0.5.107`.
2. В GitHub `app/main.py` есть `apply_accounting_receipt_data_fix()`.
3. Сделайте hard refresh браузера.
4. В нужном месяце нажмите `Обновить` — уже сохранённые чеки будут перечитаны через QR/KGD и визуальный fallback только для отсутствующих полей.
