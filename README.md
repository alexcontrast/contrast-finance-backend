# Contrast Finance v0.5.71

Точечное исправление редактора смет после глубокой ревизии `v0.5.70`: ложные конфликты версий, пустые временные строки и нестабильное перемещение позиций.

## Исправлено

- Открытие сметы больше не пишет в базу и не меняет `updated_at`; один браузер не конфликтует сам с собой.
- Админка и кабинет менеджера всегда обновляют локальную ревизию после сохранения строк, КГД, заявок и других действий с мероприятием.
- Старые ревизии админского редактора очищаются при закрытии и не переносятся в следующее открытие.
- Повторное нажатие «Добавить позицию» не создаёт несколько пустых строк.
- Пустая временная строка не попадает в API, кэш карточки или локальную резервную копию; ручное сохранение убирает её безопасно.
- Восстановленные черновики автоматически исправляют повторяющиеся временные ID и токены создания.
- Drag-and-drop корректно перемещает строку вверх и вниз, позволяет поставить её первой после координатора и сохраняет новый порядок.
- Перемещение строк работает одинаково в кабинете менеджера и в админском редакторе.

## Деплой

Развернуть `v0.5-2.71_CHANGED_ONLY.zip` поверх текущего `v0.5-2.70` либо использовать полный архив `v0.5-2.71_FULL.zip`.

Схема базы данных и финансовые формулы не менялись, новых миграций нет.
