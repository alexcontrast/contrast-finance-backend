# Contrast Finance v0.5.67

Оптимизация загрузки общей годовой статистики в админке.

## Изменено

- Вкладка больше не строит 12 полных архивных экспортов при каждом открытии.
- Все необходимые данные за год загружаются пакетно и группируются по месяцам одним проходом.
- Заявки на оплату и подробные строки Google Sheets не собираются для экранной статистики.
- Контрольный результат полностью совпадает со старым расчётом; SQL-запросов стало 8 вместо 132 на тестовом полном году.
- Экспорт Google Sheets и финансовые формулы не менялись.

## Деплой

Развернуть `v0.5.67_CHANGED_ONLY.zip` поверх текущего `v0.5.66`.

Изменён только backend-сборщик статистики. Схема базы данных не менялась, новых миграций нет.
