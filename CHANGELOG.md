# Changelog

## v0.5.108 — clean receipt pipeline, Kaspi QR and untracked special payments

- Убрано подключение runtime monkeypatch; рабочая логика встроена в основной маршрут и `app.js`.
- Дата чека стала единственным источником бухгалтерского месяца; upload/event date больше не подменяет отсутствующую дату.
- Чеки без даты вынесены в явную очередь исправления `Дата не распознана`.
- Исправлены казахские ФИО, OCR `kaz+rus+eng`, ИИН из русских/казахских KGD-ключей и восстановление идентичности по истории.
- Номер чека ограничен 12 цифрами; лишний ведущий OCR-символ отбрасывается безопасно.
- Добавлена проверенная обработка официального QR Kaspi и структурированной Nuxt-карточки чека.
- Для Координатора и ЗП менеджера добавлен способ `Самозанятый`, обязательная фамилия и нулевые вычеты/НДС; способ не фиксируется на позиции.
- Удалена дублирующая Alembic-ревизия, отдельные JS/date patch-файлы и вложенная копия `app/app`.
- Версия backend/browser: `0.5.108`; новой миграции нет.

## v0.5.107 — e-Salyq parser actually wired

- Реально подключён runtime parser fix в `app/main.py`.
- Backend version поднята до `0.5.107`.
- Исправлен выбор даты чека из KGD: русские/казахские строки, ISO, Unix, Java/Jackson arrays/objects.
- Технические create/upload/response timestamps не считаются датой чека.
- Полная Unicode-обработка ФИО, включая казахские буквы.
- Резервный Tesseract worker теперь запускается с `kaz+rus+eng`, с fallback на `rus+eng`.
- Усилен поиск ИИН исполнителя; исключается БИН заказчика.
- Номер чека выбирается из `check/receipt number` или печатной строки `Чек №...`; `check_id`/`ip_reg_id` исключены.
- Обновлены browser cache-busters.
- БД/Alembic не менялись.
