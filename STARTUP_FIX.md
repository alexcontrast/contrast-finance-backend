# Contrast Finance 0.6.6 — совместимость запуска

Патч заменяет только `scripts/start.sh`. Наложите его на репозиторий установленной 0.6.6 с заменой этого файла и выполните обычный Deploy.

В 0.6.5 startup удалял устаревший `alembic/versions/0010_monthly_closing_head_percent_overrides.py`. В 0.6.6 эта очистка была убрана; при установке поверх старого репозитория оставшийся файл может создать дополнительную конечную миграцию. Патч возвращает прежнее поведение только для этого известного файла. Правильный `0010_head_pct_overrides.py` и остальные миграции сохраняются.

До обновления выводится `alembic heads --verbose`. Если лишняя ветка имеет другое происхождение, запуск по-прежнему остановится и лог покажет её точный revision/path. Пришлите этот лог для адресной проверки. Не заменяйте `head` на `heads`, не выполняйте stamp, downgrade и объединение неизвестных веток наугад.

Патч не выполняет прямых SQL-исправлений, не сбрасывает БД и не добавляет миграций. После устранения известного конфликта выполняется штатный `alembic upgrade head` версии 0.6.6, включая её две новые миграции. Резервная копия перед обновлением остаётся необходимой.

Проверено на копии исходников: чистая цепочка и искусственно восстановленная старая ветка дают одну вершину `0023_durable_signing`; неизвестная дополнительная ветка не удаляется и блокирует запуск. Проверка графа реальная; SQL-обновление и Uvicorn в этом изолированном тесте подменены. Production не изменялся.
